Adaptive Array Demo

A deliberately dense q1timeline simulation that demonstrates adaptive multi-lane feedback behavior. It is not a hardware recipe and it does not claim a real LINQ throughput number.

The analyzed shape contains 17 sequencers, 874 timeline events, and 27 feedback flows.

What This Demo Shows

Adaptive feedback topology

Four readout lanes publish IQ feedback, four tracker lanes consume those payloads, and an arbiter turns tracker decisions into drive grants for the next control window.

Timeline pressure

Dense telemetry feedback intentionally leaves Channel 60 over-produced, so the feedback balance panel has meaningful pressure to inspect instead of a perfectly clean toy example.

Failure visibility

Channel 61 is popped too early on purpose, creating a feedback_latency_violation diagnostic that is easy to locate in the preview.

Sequencer Groups

Drive lanes drive_q0 through drive_q3 apply gain, frequency, phase, marker, and reset pulses.
Readout lanes readout_q0 through readout_q3 acquire IQ data and publish two feedback payloads per lane.
Tracker lanes Trackers drain IQ payloads, compute a simple slope, branch on it, and send two values to the arbiter.
Arbiter The arbiter drains tracker messages, emits grants, and creates a telemetry burst for load inspection.
Audit and fault lanes Audit scopes add visual play/acquire activity; the fault probe demonstrates a deliberate latency violation.

LINQ Channels

Channel range Role Expected behavior
20-23 Readout IQ feedback Balanced. Each readout acquire contributes two payload slots, and each tracker pops two values.
30-33 Tracker to arbiter Balanced. Each tracker sends a decision and a slope estimate.
40-43 Arbiter to drive grants Balanced. Each drive lane waits for one grant payload.
60 Telemetry pressure Over-produced. Eight payloads are sent and six are consumed, leaving two unconsumed payloads.
61 Fault probe Balanced in count, but popped too early to trigger the latency diagnostic.

What To Inspect In Q1Lens

Branch regions

Tracker slope checks and arbiter grant decisions are intentionally unresolved, so Q1Lens marks branch regions instead of pretending a runtime path is known.

Latched state

Drive and audit lanes stage gain, frequency, phase, marker, and scope changes before upd_param applies them.

Feedback balance

Compare balanced data channels with Channel 60 to see how leftover payload pressure is represented in the rendered timeline.
